# 狼人杀赛事平台系统 API 接口文档

## 文档说明
- **版本**: v1.0
- **基础URL**: `http://localhost:3000/`
- **数据格式**: JSON
- **字符编码**: UTF-8

## 1. 统一响应格式

### 1.1 成功响应
```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1634567890123
}
```

### 1.2 错误响应
```json
{
  "code": 400,
  "message": "错误描述",
  "data": null,
  "timestamp": 1634567890123
}
```

### 1.3 状态码说明
| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 客户端错误 |
| 401 | 未授权 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 2. 认证与授权

### 2.1 Token 获取
- **接口**: `/auth/token`
- **方法**: POST
- **描述**: 获取访问令牌

**请求头**:
```
Content-Type: application/json
```

**请求参数**:
```json
{
  "grant_type": "password",
  "username": "user@example.com",
  "password": "password123",
  "client_id": "web_app"
}
```

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires_in": 7200,
    "token_type": "Bearer"
  }
}
```

### 2.2 Token 刷新
- **接口**: `/auth/refresh`
- **方法**: POST

## 3. 用户管理模块

### 3.1 用户注册
- **接口**: `/users/register`
- **方法**: POST
- **描述**: 用户注册

**请求参数**:
```json
{
  "username": "wolf_player",
  "email": "user@example.com",
  "password": "password123",
  "nickname": "狼人杀高手",
  "phone": "13800138000",
  "avatar_url": "https://example.com/avatar.jpg",
  "birthdate": "1990-01-01"
}
```

### 3.2 用户登录
- **接口**: `/users/login`
- **方法**: POST

### 3.3 获取用户信息
- **接口**: `/users/{user_id}`
- **方法**: GET
- **需要认证**: 是

**响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": 123,
    "username": "wolf_player",
    "nickname": "狼人杀高手",
    "email": "user@example.com",
    "avatar_url": "https://example.com/avatar.jpg",
    "level": 5,
    "experience": 12500,
    "gold_coins": 5000,
    "diamonds": 100,
    "created_at": "2023-01-01T00:00:00Z"
  }
}
```

### 3.4 更新用户信息
- **接口**: `/users/{user_id}`
- **方法**: PUT
- **需要认证**: 是

### 3.5 修改密码
- **接口**: `/users/{user_id}/password`
- **方法**: PUT
- **需要认证**: 是

## 4. 战队管理模块

### 4.1 创建战队
- **接口**: `/teams`
- **方法**: POST
- **需要认证**: 是

**请求参数**:
```json
{
  "name": "狼人联盟",
  "description": "专业狼人杀战队",
  "logo_url": "https://example.com/logo.png",
  "max_members": 20,
  "join_type": "approval",
  "tags": ["专业", "竞技", "娱乐"]
}
```

### 4.2 获取战队列表
- **接口**: `/teams`
- **方法**: GET

**查询参数**:
- `page` (可选): 页码，默认1
- `size` (可选): 每页数量，默认20
- `keyword` (可选): 搜索关键词
- `sort_by` (可选): 排序字段

### 4.3 获取战队详情
- **接口**: `/teams/{team_id}`
- **方法**: GET

### 4.4 更新战队信息
- **接口**: `/teams/{team_id}`
- **方法**: PUT
- **需要认证**: 是（仅队长）

### 4.5 解散战队
- **接口**: `/teams/{team_id}`
- **方法**: DELETE
- **需要认证**: 是（仅队长）

### 4.6 申请加入战队
- **接口**: `/teams/{team_id}/applications`
- **方法**: POST
- **需要认证**: 是

### 4.7 战队成员管理
- **接口**: `/teams/{team_id}/members`
- **方法**: GET/POST/DELETE

## 5. 赛事系统模块

### 5.1 创建赛事
- **接口**: `/tournaments`
- **方法**: POST
- **需要认证**: 是

**请求参数**:
```json
{
  "title": "2023狼人杀全国大赛",
  "description": "年度最高级别赛事",
  "start_time": "2023-12-01T10:00:00Z",
  "end_time": "2023-12-31T18:00:00Z",
  "max_teams": 32,
  "min_players_per_team": 6,
  "max_players_per_team": 12,
  "entry_fee": {
    "type": "gold_coins",
    "amount": 1000
  },
  "prizes": [
    {
      "rank": 1,
      "prize": "冠军奖杯+10000钻石"
    }
  ],
  "rules": "赛事详细规则...",
  "cover_image": "https://example.com/tournament.jpg"
}
```

### 5.2 获取赛事列表
- **接口**: `/tournaments`
- **方法**: GET

**查询参数**:
- `status` (可选): 状态（upcoming, ongoing, finished）
- `type` (可选): 赛事类型
- `page`, `size`: 分页参数

### 5.3 赛事报名
- **接口**: `/tournaments/{tournament_id}/registrations`
- **方法**: POST
- **需要认证**: 是

**请求参数**:
```json
{
  "team_id": 123,
  "players": [
    {
      "user_id": 1,
      "role": "captain"
    },
    {
      "user_id": 2,
      "role": "player"
    }
  ]
}
```

### 5.4 赛事对战管理
- **接口**: `/tournaments/{tournament_id}/matches`
- **方法**: GET/POST

### 5.5 提交比赛结果
- **接口**: `/matches/{match_id}/result`
- **方法**: POST
- **需要认证**: 是（裁判）

**请求参数**:
```json
{
  "winner_team_id": 123,
  "scores": [
    {
      "user_id": 1,
      "score": 85,
      "mvp": true
    }
  ],
  "game_log": "对局详细记录...",
  "replay_url": "https://example.com/replay.mp4"
}
```

---

**注意**: 
1. 所有需要认证的接口需要在请求头中添加：`Authorization: Bearer {access_token}`
2. 时间格式统一使用 ISO 8601: `YYYY-MM-DDTHH:mm:ssZ`
3. 分页参数统一使用 `page` 和 `size`
4. 所有金额单位均为最小单位（如分、金币数）
