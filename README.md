# Online Game Server

一个基于Node.js的多功能在线游戏和社交平台服务器，提供实时通信、游戏房间、用户管理等功能。

## 技术栈

- **后端框架**: Express.js
- **实时通信**: Socket.io
- **数据库**: MongoDB
- **开发语言**: TypeScript
- **构建工具**: Webpack
- **缓存**: Redis

## 核心功能

### 1. 用户系统
- 用户注册和登录
- JWT认证
- 角色权限管理
- 用户资料管理

### 2. 房间系统
- 实时房间创建和管理
- WebSocket实时通信
- 用户在线状态管理
- 房间消息广播

### 3. 游戏系统
- 多种游戏模式支持
- 游戏状态管理
- 实时游戏同步
- 游戏数据统计

### 4. 物品系统
- 背包管理
- 物品交易
- 奖励系统
- 邮箱系统

### 5. 其他功能
- 文件上传
- 图片服务
- 管理后台
- 公告系统
- 投票系统

## 项目结构

```
├── src/
│   ├── Admin/          # 管理后台
│   ├── controller/     # 控制器
│   ├── core/          # 核心功能
│   ├── db/            # 数据库相关
│   ├── middlewares/   # 中间件
│   ├── models/        # 数据模型
│   ├── routes/        # 路由
│   ├── services/      # 服务
│   ├── socket/        # WebSocket处理
│   └── utils/         # 工具函数
├── config/            # 配置文件
├── types/             # TypeScript类型定义
└── public/            # 静态资源
```

- 🚀 高性能WebSocket通信

## 环境要求

- Node.js >= 14
- MongoDB >= 4.0
- Redis >= 6.0

## 配置文件

项目使用.env文件进行配置管理：
- `.env`: 开发环境配置
- `.env.test`: 测试环境配置
- `.env.prod`: 生产环境配置

## 安全特性

- JWT身份验证
- 请求去重
- CORS配置
- 角色权限控制
- 维护模式"# myServer-2"
