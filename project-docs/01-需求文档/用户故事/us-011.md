# 用户故事文档

## 赛事模块
### US-011: 管理赛事报名
**作为** 赛事管理员
**我想要** 管理赛事的报名信息
**以便于** 控制参赛人员

**验收标准**：
- **场景1**: 审核报名
  - Given: 赛事处于报名中状态，且有用户提交了报名申请
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员查看待审核的报名列表
  - When: 赛事管理员选择一个报名申请，点击审核通过按钮
  - Then: 系统应将该用户的报名状态改为已通过
  - Then: 系统应向该用户发送报名通过的通知
  - Then: 该用户应显示在已报名列表中
  - Then: 该用户应能查看赛事详情和赛程安排

- **场景2**: 拒绝报名
  - Given: 赛事处于报名中状态，且有用户提交了报名申请
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员查看待审核的报名列表
  - When: 赛事管理员选择一个报名申请，点击拒绝按钮
  - When: 赛事管理员输入拒绝原因（可选）
  - When: 赛事管理员确认拒绝操作
  - Then: 系统应将该用户的报名状态改为已拒绝
  - Then: 系统应向该用户发送报名拒绝的通知，包含拒绝原因（如有）
  - Then: 该用户应从待审核列表中移除
  - Then: 该用户应无法查看赛事详情和赛程安排

- **场景3**: 查看报名列表
  - Given: 赛事处于报名中或已结束报名状态
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员点击查看报名列表
  - Then: 系统应显示所有报名该赛事的用户列表
  - Then: 列表应包含用户的基本信息、报名状态、报名时间等
  - Then: 赛事管理员应能根据报名状态筛选列表
  - Then: 赛事管理员应能导出报名列表

- **场景4**: 取消报名
  - Given: 用户已成功报名赛事
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员选择一个已报名的用户，点击取消报名按钮
  - When: 赛事管理员输入取消原因（可选）
  - When: 赛事管理员确认取消操作
  - Then: 系统应将该用户的报名状态改为已取消
  - Then: 系统应向该用户发送报名取消的通知，包含取消原因（如有）
  - Then: 该用户应从已报名列表中移除
  - Then: 该用户应无法查看赛事详情和赛程安排
