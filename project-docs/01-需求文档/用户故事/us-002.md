# 用户故事文档

## 用户模块
### US-002: 查看赛事列表
**作为** 普通用户
**我想要** 查看平台上的赛事列表
**以便于** 找到感兴趣的赛事

**验收标准**：
- **场景1**: 查看所有赛事
  - Given: 用户已成功登录平台
  - When: 用户进入赛事列表页面
  - Then: 系统应显示所有赛事的列表
  - Then: 每个赛事应显示赛事名称、类型、状态、开始时间和报名截止时间
  - Then: 赛事应按开始时间倒序排列

- **场景2**: 筛选赛事
  - Given: 用户已成功登录平台
  - When: 用户选择筛选条件（如赛事状态、类型、难度等）
  - Then: 系统应根据筛选条件显示匹配的赛事
  - Then: 筛选结果应实时更新
  - Then: 系统应显示当前筛选条件

- **场景3**: 搜索赛事
  - Given: 用户已成功登录平台
  - When: 用户在搜索框中输入赛事名称或关键词
  - Then: 系统应显示名称或关键词匹配的赛事
  - Then: 搜索结果应实时更新
  - Then: 搜索结果应突出显示匹配的关键词
  - Then: 当搜索框为空时，应显示所有赛事
