# 用户故事文档

## 战队模块
### US-005: 管理战队成员
**作为** 战队队长
**我想要** 管理战队成员
**以便于** 控制战队人员构成

**验收标准**：
- **场景1**: 邀请成员
  - Given: 用户是战队队长
  - When: 用户进入战队管理页面，点击邀请成员按钮
  - When: 用户输入邀请码或选择平台用户
  - When: 用户发送邀请
  - Then: 系统应生成邀请码或发送邀请通知
  - Then: 被邀请用户应收到加入战队的邀请

- **场景2**: 移除成员
  - Given: 用户是战队队长，战队中有其他成员
  - When: 用户进入战队成员列表，选择要移除的成员
  - When: 用户点击移除按钮
  - When: 用户确认移除操作
  - Then: 系统应将该成员从战队中移除
  - Then: 被移除成员应收到战队移除通知
  - Then: 被移除成员的战队信息应更新

- **场景3**: 设置管理员
  - Given: 用户是战队队长，战队中有其他成员
  - When: 用户进入战队成员列表，选择要设置为管理员的成员
  - When: 用户点击设为管理员按钮
  - Then: 系统应将该成员的角色从普通成员变为战队管理员
  - Then: 该成员应获得战队管理员的权限
  - Then: 战队成员列表中应显示该成员的管理员身份

- **场景4**: 取消管理员
  - Given: 用户是战队队长，战队中有战队管理员
  - When: 用户进入战队成员列表，选择要取消管理员的成员
  - When: 用户点击取消管理员按钮
  - Then: 系统应将该成员的角色从战队管理员变为普通成员
  - Then: 该成员应失去战队管理员的权限
  - Then: 战队成员列表中应更新该成员的身份
