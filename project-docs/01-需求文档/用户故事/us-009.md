# 用户故事文档

## 赛事模块
### US-009: 创建赛事
**作为** 赛事创建者
**我想要** 创建新的赛事
**以便于** 组织狼人杀比赛

**验收标准**：
- **场景1**: 成功创建赛事
  - Given: 赛事创建者进入赛事管理页面
  - When: 赛事创建者点击创建赛事按钮
  - When: 赛事创建者填写赛事名称、时间、地点、规则等信息
  - When: 赛事创建者点击发布按钮
  - Then: 系统应验证赛事名称的唯一性
  - Then: 系统应创建赛事，并将用户设置为赛事创建者
  - Then: 系统应显示创建成功提示
  - Then: 赛事创建者应能在赛事列表中看到该赛事
  - Then: 赛事状态应显示为"未开始"

- **场景2**: 创建失败（名称重复）
  - Given: 平台上已存在同名赛事
  - When: 赛事创建者使用该名称创建赛事
  - Then: 系统应显示友好的错误提示，说明赛事名称已存在
  - Then: 赛事创建者应无法创建赛事

- **场景3**: 创建失败（信息不完整）
  - Given: 赛事创建者未填写必填信息（如赛事名称、开始时间）
  - When: 赛事创建者点击发布按钮
  - Then: 系统应显示友好的错误提示，指出缺少的必填信息
  - Then: 赛事创建者应无法创建赛事

- **场景4**: 创建草稿
  - Given: 赛事创建者进入创建赛事页面
  - When: 赛事创建者填写部分赛事信息
  - When: 赛事创建者点击保存草稿按钮
  - Then: 系统应保存该赛事草稿
  - Then: 赛事创建者可在草稿列表中找到该赛事
  - Then: 赛事创建者可继续编辑该草稿并发布
  - Then: 草稿赛事不应在公开赛事列表中显示
