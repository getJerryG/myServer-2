# 用户故事文档

## 赛事模块
### US-012: 管理赛事状态
**作为** 赛事管理员
**我想要** 管理赛事的状态
**以便于** 控制赛事流程

**验收标准**：
- **场景1**: 更改赛事状态为报名中
  - Given: 赛事处于未开始状态
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员点击开始报名按钮
  - When: 赛事管理员确认操作
  - Then: 系统应将赛事状态从"未开始"改为"报名中"
  - Then: 系统应向关注该赛事的用户发送报名开始通知
  - Then: 普通用户应能看到该赛事并进行报名
  - Then: 赛事详情页面应显示报名入口

- **场景2**: 更改赛事状态为进行中
  - Given: 赛事处于报名中状态，且报名时间已结束
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员点击开始赛事按钮
  - When: 赛事管理员确认操作
  - Then: 系统应将赛事状态从"报名中"改为"进行中"
  - Then: 系统应向已报名用户发送赛事开始通知
  - Then: 普通用户应无法再报名该赛事
  - Then: 赛事详情页面应显示赛事进行中的标识
  - Then: 赛事管理员应能管理赛程和比赛

- **场景3**: 更改赛事状态为已结束
  - Given: 赛事处于进行中状态，且所有比赛已完成
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员点击结束赛事按钮
  - When: 赛事管理员确认操作
  - Then: 系统应将赛事状态从"进行中"改为"已结束"
  - Then: 系统应向所有参赛用户发送赛事结束通知
  - Then: 赛事详情页面应显示赛事已结束的标识
  - Then: 赛事结果应可见
  - Then: 赛事管理员应能查看和导出赛事数据

- **场景4**: 更改赛事状态为已取消
  - Given: 赛事处于未开始或报名中状态
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员点击取消赛事按钮
  - When: 赛事管理员输入取消原因
  - When: 赛事管理员确认操作
  - Then: 系统应将赛事状态改为"已取消"
  - Then: 系统应向所有已报名用户发送赛事取消通知，并退还报名费（如有）
  - Then: 普通用户应无法再报名该赛事
  - Then: 赛事详情页面应显示赛事已取消的标识和原因

- **场景5**: 错误的状态转换
  - Given: 赛事处于已结束状态
  - When: 赛事管理员尝试将赛事状态改为报名中
  - Then: 系统应显示友好的错误提示，说明不能从已结束状态转换到报名中状态
  - Then: 赛事状态应保持为已结束
