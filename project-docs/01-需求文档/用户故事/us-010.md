# 用户故事文档

## 赛事模块
### US-010: 设置赛事规则
**作为** 赛事创建者
**我想要** 设置赛事的规则和赛制
**以便于** 确保赛事顺利进行

**验收标准**：
- **场景1**: 设置基本规则
  - Given: 赛事创建者已创建赛事
  - When: 赛事创建者进入赛事编辑页面
  - When: 赛事创建者设置赛事的基本规则，如参赛人数、报名费、奖励等
  - When: 赛事创建者点击保存按钮
  - Then: 系统应保存这些规则设置
  - Then: 赛事详情页面应显示这些规则
  - Then: 用户查看赛事详情时应能看到这些规则

- **场景2**: 设置赛制
  - Given: 赛事创建者已创建赛事
  - When: 赛事创建者进入赛事编辑页面
  - When: 赛事创建者设置赛事的赛制，如晋级规则、轮次安排等
  - When: 赛事创建者点击保存按钮
  - Then: 系统应保存这些赛制设置
  - Then: 赛事详情页面应显示这些赛制
  - Then: 赛事管理员应能根据这些赛制管理赛事流程

- **场景3**: 设置奖励
  - Given: 赛事创建者已创建赛事
  - When: 赛事创建者进入赛事编辑页面
  - When: 赛事创建者设置赛事的奖励，如奖金、礼品、积分等
  - When: 赛事创建者点击保存按钮
  - Then: 系统应保存这些奖励设置
  - Then: 赛事详情页面应显示这些奖励
  - Then: 赛事结果页面应根据这些奖励设置显示获奖信息

- **场景4**: 修改规则
  - Given: 赛事已创建且未开始
  - When: 赛事创建者进入赛事编辑页面
  - When: 赛事创建者修改赛事规则
  - When: 赛事创建者点击保存按钮
  - Then: 系统应更新赛事规则
  - Then: 系统应显示规则已更新的提示
  - Then: 赛事详情页面应显示更新后的规则

- **场景5**: 赛事已开始后修改规则
  - Given: 赛事已开始
  - When: 赛事创建者尝试修改赛事规则
  - Then: 系统应显示警告提示，说明赛事已开始，修改规则可能影响赛事公平性
  - When: 赛事创建者确认要修改
  - Then: 系统应允许修改规则
  - Then: 系统应记录规则修改记录
  - Then: 赛事参与者应收到规则更新通知
