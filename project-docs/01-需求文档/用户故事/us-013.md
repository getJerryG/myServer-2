# 用户故事文档

## 赛事模块
### US-013: 管理赛事结果
**作为** 赛事管理员
**我想要** 管理赛事的结果
**以便于** 公布比赛成绩

**验收标准**：
- **场景1**: 录入比赛结果
  - Given: 赛事处于进行中状态，且有已完成的比赛
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员选择已完成的比赛，点击录入结果按钮
  - When: 赛事管理员填写比赛结果，包括获胜方、选手得分等信息
  - When: 赛事管理员点击保存按钮
  - Then: 系统应保存该比赛的结果
  - Then: 该比赛的状态应改为已完成
  - Then: 选手的个人成绩应更新
  - Then: 赛事的总成绩排名应更新

- **场景2**: 修改比赛结果
  - Given: 赛事管理员已录入比赛结果
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员选择已录入结果的比赛，点击修改结果按钮
  - When: 赛事管理员修改比赛结果
  - When: 赛事管理员点击保存按钮
  - Then: 系统应更新该比赛的结果
  - Then: 选手的个人成绩应重新计算
  - Then: 赛事的总成绩排名应重新生成
  - Then: 系统应记录结果修改日志

- **场景3**: 公布比赛结果
  - Given: 赛事管理员已录入所有比赛结果
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员点击公布结果按钮
  - When: 赛事管理员确认操作
  - Then: 系统应将赛事结果设置为可见状态
  - Then: 系统应向所有参赛用户发送结果公布通知
  - Then: 普通用户应能查看赛事结果
  - Then: 赛事详情页面应显示完整的比赛结果和排名

- **场景4**: 查看和导出结果数据
  - Given: 赛事已结束，且结果已公布
  - When: 赛事管理员进入赛事管理页面
  - When: 赛事管理员点击查看结果按钮
  - Then: 系统应显示完整的赛事结果，包括各轮次成绩和最终排名
  - Then: 赛事管理员应能按选手、轮次等筛选结果
  - When: 赛事管理员点击导出结果按钮
  - Then: 系统应生成并下载赛事结果数据文件
  - Then: 导出的文件应包含所有比赛结果和统计数据

- **场景5**: 错误的结果操作
  - Given: 赛事未开始或处于报名中状态
  - When: 赛事管理员尝试录入比赛结果
  - Then: 系统应显示友好的错误提示，说明赛事尚未开始或未到录入结果阶段
  - Then: 赛事管理员应无法录入结果
