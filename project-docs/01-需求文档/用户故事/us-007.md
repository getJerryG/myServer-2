# 用户故事文档

## 战队模块
### US-007: 管理战队申请
**作为** 战队管理员
**我想要** 管理用户的战队加入申请
**以便于** 协助队长管理战队

**验收标准**：
- **场景1**: 通过申请
  - Given: 战队管理员进入战队管理页面
  - When: 战队管理员查看待处理的战队加入申请
  - When: 战队管理员选择一个申请，点击通过按钮
  - Then: 系统应将该用户加入战队
  - Then: 被通过的用户应收到加入战队成功的通知
  - Then: 战队成员列表中应显示该用户
  - Then: 战队申请列表中应移除该申请

- **场景2**: 拒绝申请
  - Given: 战队管理员进入战队管理页面
  - When: 战队管理员查看待处理的战队加入申请
  - When: 战队管理员选择一个申请，点击拒绝按钮
  - When: 战队管理员输入拒绝原因（可选）
  - When: 战队管理员确认拒绝操作
  - Then: 系统应拒绝该用户的加入申请
  - Then: 被拒绝的用户应收到加入战队失败的通知，包含拒绝原因（如有）
  - Then: 战队申请列表中应移除该申请

- **场景3**: 查看申请列表
  - Given: 战队有待处理的加入申请
  - When: 战队管理员进入战队管理页面
  - When: 战队管理员点击查看战队申请
  - Then: 系统应显示所有待处理的战队加入申请
  - Then: 每个申请应显示申请人的头像、昵称、申请时间等信息
  - Then: 战队管理员应能对每个申请进行操作（通过或拒绝）

- **场景4**: 申请列表为空
  - Given: 战队没有待处理的加入申请
  - When: 战队管理员进入战队管理页面，查看战队申请
  - Then: 系统应显示友好的提示，说明当前没有待处理的申请
  - Then: 战队管理员应无法进行通过或拒绝操作
