# 用户故事文档

## 战队模块
### US-004: 创建战队
**作为** 战队队长
**我想要** 创建自己的战队
**以便于** 组织队伍参加赛事

**验收标准**：
- **场景1**: 成功创建战队
  - Given: 用户已成功登录平台
  - When: 用户进入创建战队页面，填写战队名称、战队宣言等信息
  - When: 用户点击创建按钮
  - Then: 系统应验证战队名称的唯一性
  - Then: 系统应创建战队，并将用户设置为战队队长
  - Then: 系统应显示创建成功提示
  - Then: 用户应能看到自己创建的战队

- **场景2**: 创建失败（名称重复）
  - Given: 平台上已存在同名战队
  - When: 用户使用该名称创建战队
  - Then: 系统应显示友好的错误提示，说明战队名称已存在
  - Then: 用户应无法创建战队

- **场景3**: 创建失败（信息不完整）
  - Given: 用户未填写必填信息（如战队名称）
  - When: 用户点击创建按钮
  - Then: 系统应显示友好的错误提示，指出缺少的必填信息
  - Then: 用户应无法创建战队

- **场景4**: 已有战队
  - Given: 用户已创建或加入了其他战队
  - When: 用户尝试再次创建战队
  - Then: 系统应显示友好的错误提示，说明用户已有战队
  - Then: 用户应无法创建新战队
