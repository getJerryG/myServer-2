# 用户故事文档

## 战队模块
### US-006: 战队报名赛事
**作为** 战队队长
**我想要** 代表战队报名参加赛事
**以便于** 组织队伍参赛

**验收标准**：
- **场景1**: 成功报名
  - Given: 赛事支持战队报名，且战队人数符合赛事要求
  - When: 战队队长进入赛事详情页面，点击战队报名按钮
  - When: 战队队长确认报名信息和参赛成员
  - When: 战队队长点击确认报名
  - Then: 系统应验证战队是否符合报名条件
  - Then: 系统应处理报名请求，扣除报名费（如有）
  - Then: 系统应显示报名成功提示
  - Then: 战队的赛事列表中应显示该赛事

- **场景2**: 报名失败（赛事不支持战队报名）
  - Given: 赛事仅支持个人报名
  - When: 战队队长尝试以战队名义报名
  - Then: 系统应显示友好的错误提示，说明赛事不支持战队报名
  - Then: 战队队长应无法以战队名义报名
  - Then: 系统应提示战队队长可以以个人身份报名

- **场景3**: 报名失败（战队人数不足）
  - Given: 赛事要求战队人数至少为5人，但战队当前只有3人
  - When: 战队队长尝试报名该赛事
  - Then: 系统应显示友好的错误提示，说明战队人数不足
  - Then: 战队队长应无法完成报名
  - Then: 系统应提示战队队长还需要招募多少成员

- **场景4**: 已报名赛事
  - Given: 战队已成功报名该赛事
  - When: 战队队长再次尝试报名
  - Then: 系统应显示友好的提示，说明战队已报名该赛事
  - Then: 战队队长应无法重复报名
