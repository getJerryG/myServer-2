# 用户故事文档

## 战队模块
### US-008: 发布战队公告
**作为** 战队管理员
**我想要** 发布战队公告
**以便于** 向战队成员传达重要信息

**验收标准**：
- **场景1**: 成功发布公告
  - Given: 战队管理员进入战队管理页面
  - When: 战队管理员点击发布公告按钮
  - When: 战队管理员填写公告标题和内容
  - When: 战队管理员点击发布按钮
  - Then: 系统应保存该公告
  - Then: 战队成员应收到新公告通知
  - Then: 战队公告列表中应显示该公告
  - Then: 公告应显示发布时间和发布人信息

- **场景2**: 编辑公告
  - Given: 战队管理员已发布过公告
  - When: 战队管理员进入战队公告列表
  - When: 战队管理员选择一个已发布的公告，点击编辑按钮
  - When: 战队管理员修改公告内容
  - When: 战队管理员点击保存按钮
  - Then: 系统应更新该公告的内容
  - Then: 战队成员应收到公告更新通知
  - Then: 战队公告列表中应显示更新后的公告
  - Then: 公告应显示更新时间

- **场景3**: 删除公告
  - Given: 战队管理员已发布过公告
  - When: 战队管理员进入战队公告列表
  - When: 战队管理员选择一个已发布的公告，点击删除按钮
  - When: 战队管理员确认删除操作
  - Then: 系统应删除该公告
  - Then: 战队公告列表中应移除该公告
  - Then: 战队成员应无法再查看该公告

- **场景4**: 公告列表管理
  - Given: 战队有多个已发布的公告
  - When: 战队管理员进入战队公告列表
  - Then: 系统应按发布时间倒序显示所有公告
  - Then: 每个公告应显示标题、发布时间、发布人和内容摘要
  - Then: 战队管理员应能对每个公告进行编辑或删除操作

- **场景5**: 查看公告详情
  - Given: 战队有已发布的公告
  - When: 战队管理员或普通成员点击某个公告
  - Then: 系统应显示公告的完整内容
  - Then: 应显示公告的发布时间、发布人和更新时间（如有）
