# 用户故事文档

## 用户模块
### US-003: 报名赛事
**作为** 普通用户
**我想要** 报名参加感兴趣的赛事
**以便于** 获得参赛资格

**验收标准**：
- **场景1**: 成功报名
  - Given: 赛事处于报名中状态，且报名人数未达上限
  - When: 用户点击报名按钮
  - Then: 系统应显示报名确认页面，包含赛事信息和报名费（如有）
  - When: 用户确认报名
  - Then: 系统应处理报名请求，扣除报名费（如有）
  - Then: 系统应显示报名成功提示
  - Then: 用户的赛事列表中应显示该赛事

- **场景2**: 报名失败（赛事已结束）
  - Given: 赛事已结束或已取消
  - When: 用户点击报名按钮
  - Then: 系统应显示友好的错误提示，说明赛事已结束或已取消
  - Then: 用户应无法完成报名

- **场景3**: 报名失败（人数已满）
  - Given: 赛事报名人数已达上限
  - When: 用户点击报名按钮
  - Then: 系统应显示友好的错误提示，说明赛事人数已满
  - Then: 用户应无法完成报名

- **场景4**: 重复报名
  - Given: 用户已成功报名该赛事
  - When: 用户再次点击报名按钮
  - Then: 系统应显示友好的提示，说明用户已报名该赛事
  - Then: 用户应无法重复报名
