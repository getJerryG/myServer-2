# 赛事管理员提交选手比赛数据实现方案

## 1. 新增选手比赛数据模型

**文件**: `src/models/contest/models/ContestPlayerResultModel.ts`

* 创建 Mongoose 模型存储选手比赛结果

* 包含选手ID、昵称、得分、角色、阵营、MVP标识等字段

* 关联赛事、赛程、报名记录

## 2. 扩展 ContestRankingService

**文件**: `src/models/contest/services/ContestRankingService.ts`

* 新增 `recordPlayerResult` 方法支持选手级别数据提交

* 完善 `recordMatchResult` 方法支持多选手数据

* 实现选手数据的批量保存和更新

## 3. 创建赛事管理员专用路由

**文件**: `src/routes/contest/contestAdminRoutes.ts`

* 新增 `/contest/:id/player-result` 接口

* 实现选手比赛数据提交功能

* 添加赛事级别权限检查中间件

## 4. 实现赛事管理员权限检查中间件

**文件**: `src/middlewares/contestAdmin.ts`

* 创建赛事管理员权限验证中间件

* 检查用户是否为赛事管理员且具有 submitData 权限

* 验证用户是否有权操作指定赛事

## 5. 添加选手比赛结果类型定义

**文件**: `src/models/contest/types/contest.d.ts`

* 新增 `IPlayerResult` 接口

* 扩展 `IPlayerMatchResult` 类型

## 6. 注册新路由

**文件**: `src/routes/index.ts`

* 导入并注册赛事管理员专用路由

* 确保路由正确挂载到应用

## 7. API 接口规范

```
POST /api/contest/:id/player-result
- 功能：赛事管理员提交选手比赛数据
- 权限：赛事管理员（需赛事级别权限验证）
- 请求参数：
  - date: 比赛日期
  - round: 轮次
  - teamName: 队伍名称
  - players: 选手数据数组
    - userId: 用户ID
    - nickname: 昵称
    - score: 得分
    - role: 角色
    - faction: 阵营
    - isMvp: 是否MVP
```

5. 创建赛事管理员专用路由
