# 狼人杀赛事小程序权限系统落地实施计划

## 📋 实施概览
基于现有代码库，实施完整的RBAC权限系统，采用「资源:模块:操作」字符串格式，结合JWT + Redis缓存，实现细粒度权限控制。

## 🎯 核心目标
1. 创建权限、角色、用户角色关联三张核心表
2. 实现基于字符串权限的验证中间件和装饰器
3. 建立JWT + Redis的权限缓存机制
4. 实现权限实时更新和细粒度数据权限控制
5. 保持与现有代码的兼容性，支持渐进式迁移

## 📊 关键技术点
1. **权限字符串格式**：`resource:module:operation`
2. **Redis缓存策略**：TTL 2小时±10分钟，避免雪崩
3. **数据权限控制**：支持all/own/team/custom四种范围
4. **兼容性设计**：保留现有role字段，新增roleIds
5. **实时更新**：权限变更后主动删除Redis缓存

## ⚠️ 注意事项
1. 所有数据库操作使用事务确保数据一致性
2. Redis操作增加错误处理和重试机制
3. 权限验证失败返回标准错误码（403）
4. 保持现有API兼容性，不破坏现有功能
5. 所有新代码遵循项目规范（4空格缩进、中文注释）
