## 4. 部署说明

### 4.1 环境要求

- Node.js：v22.2.0 或以上
- TypeScript：v5.8.2 或以上
- pnpm：最新版本
- MongoDB：v6.0 或以上
- Redis：v7.0 或以上

### 4.2 部署步骤

1. 克隆代码仓库
2. 安装依赖：`pnpm install`
3. 配置环境变量：创建 `.env` 文件并配置相关参数
4. 构建项目：`pnpm run build:prod`
5. 启动服务：`pnpm run start:prod`

### 4.3 环境变量配置

```dotenv
# 服务器配置
PORT=3000
NODE_ENV=production

# MongoDB配置
MONGO_URL=mongodb://localhost:27017/werewolf

# Redis配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=

# JWT配置
JWT_SECRET=your_jwt_secret
JWT_EXPIRES_IN=7d

# 微信配置
WECHAT_APPID=your_wechat_appid
WECHAT_SECRET=your_wechat_secret

# 文件上传配置
UPLOAD_PATH=./uploads
MAX_FILE_SIZE=5242880
```

### 4.4 构建和启动命令

| 命令 | 描述 |
|------|------|
| `pnpm run build:prod` | 构建生产版本 |
| `pnpm run start:prod` | 启动生产服务 |
| `pnpm run deploy:prod` | 执行完整的生产部署流程 |
| `pnpm run docker:build` | 构建Docker镜像 |
| `pnpm run docker:run` | 运行Docker容器 |
